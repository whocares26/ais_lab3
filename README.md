**Лабораторная работа №3:** нечёткие системы логического вывода (дисциплина «Системы искусственного интеллекта»).

**Предметная область:** воронка активации пользователей, как в ЛР 1–2. Система оценивает приоритет доработки сценария (0–6 баллов) по доле достижения активации (один вход, 7 правил) и по доле достижения активации, доле выбывших по неактивности и удержанию после активации (три входа, 9 правил). Жёсткие пороги ЛР 1–2 («ниже_цели / в_пределах_цели») заменены нечёткими термами.

**Возможности:** импликации Мамдани, Ларсена, Лукасевича, Гёделя, Клини–Дайнса; агрегация max, вероятностная сумма, ограниченная сумма, min; max-min композиция; механизмы вывода — алгоритм 1 (сначала выходы правил), алгоритм 2 (сначала агрегация правил), алгоритм 3 (уровни истинности предпосылок); дефаззификация центром тяжести. Вход — чёткое число, терм, терм с модификатором («очень», «более-менее»), значения по точкам или готовый сценарий. База знаний — `data/funnel.json`, пример из лекции 4 — `data/lecture_example.json`.

**Меню:** 5 — вывод для одного входа с протоколом (матрицы R_i, выходы правил, B′, y*) и сводкой по трём механизмам, 6 — вывод для нескольких входов, 7 — сравнение импликаций, 8 — графики и таблицы для записки в `plots/`, 9 — самопроверка по контрольным значениям лекции. После y* программа печатает словесный итог — ближайший терм выхода («приоритет доработки — повышенный»).
